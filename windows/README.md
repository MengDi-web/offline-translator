# Windows 版安装说明

> **⚠ 第一步（必看）**：请先把整个压缩包**解压**到文件夹（右键 → 全部解压），
> 然后进入解压出来的文件夹。**不要**在压缩包里面直接双击运行脚本，
> 否则会报"找不到 server.js"。

本翻译器为**完全离线**的本地网页翻译：服务启动后，在浏览器里输入网址即可使用，不需要安装任何软件。

## 安装步骤（只需两步）

> **⚠ 重要**：请把压缩包解压到**纯英文路径**（例如 `D:\miaomiao`），
> 不要放在中文文件夹或微信/QQ 的接收目录里——中文路径会导致翻译模型加载失败。
> 同样不要放在「下载」等系统会清理的目录。

1. **双击「install.cmd」** → 自动准备 Node / Python / 依赖 / 模型（首次约 5-10 分钟，**完整版无需联网**，全程不用操作）

2. **之后每次使用：双击「start.bat」** → 保持黑色窗口打开
   → **会自动弹出独立窗口**（无地址栏，像软件一样，无需手动输网址）
   → 如果窗口没弹出：打开浏览器，地址栏输入 `http://127.0.0.1:6688` 回车即可翻译。

> 说明：`start.bat` 的黑色窗口就是服务本身，**不要关闭**，关掉它就停止翻译了。
> 划词助手会随start.bat 自动运行（托盘图标，最小化窗口）。

## 如果提示缺少运行库

极少数干净的 Windows 可能缺少微软 VC++ 运行库，install.cmd 会明确提示。
若出现「翻译依赖无法加载」：双击安装包内 `offline\vc_redist.x64.exe` 安装（需管理员确认，一次即可），
然后重新运行 install.cmd。

## 划词翻译（可选）

1. 在网页上**点一次「开启一键划词」**按钮（只需一次）
2. 之后在**任何软件**里选中文字 → **Ctrl+C**（复制）→ 鼠标旁弹出翻译
3. 右键**托盘图标**可设置/退出（托盘 = 屏幕右下角时间旁的小箭头里）

> 划词不依赖网页开着：开启后关掉浏览器也能用（只要黑色窗口没关）。

## 常见问题

- **双击start.bat 提示"未找到 Node.js"** → 说明还没运行过「install.cmd」，先运行它
- **浏览器打不开页面** → 确认黑色窗口还开着；地址栏输入的是 `http://127.0.0.1:6688`（不是别的）
- **首次被 Windows 提示** → 选「仍要运行」即可

## 系统要求

- Windows 10 / 11（64 位）
- 首次部署需要联网（之后使用完全离线，不上传任何内容）
