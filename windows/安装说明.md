# Windows 版安装说明

本翻译器为**跨平台**设计：服务端（Node.js + 词典引擎）完全跨平台；
神经翻译（Python）跨平台；划词助手提供 Windows 原生版本（PowerShell，免编译）。

## 安装步骤

1. **安装 Node.js**（必须）: https://nodejs.org （LTS 版即可，一路下一步）

2. **准备词典数据**（若仓库不含 data/ 目录，需联网生成一次）:
   ```
   node tools/fetch-data.js
   node tools/build-index.js
   ```

3. **获取神经模型**（二选一）:
   - 已下载微调模型 → 放到 `neural/models/opus-mt-zh-en-ft/` 和 `opus-mt-en-zh-ft/`
   - 或运行 `node tools/fetch-models.js`（从 GitHub Release 或 hf-mirror 自动下载）

4. **（可选，推荐）安装 Python 神经后端**:
   ```
   python -m venv neural\.venv
   neural\.venv\Scripts\pip install torch transformers sentencepiece sacrebleu
   ```
   > 没有 Python 也能用：自动降级为纯词典引擎（词/短语翻译），句子走逐词直译。

5. **一键启动**（服务 + 划词助手）:
   ```
   双击 windows\启动翻译器.bat
   ```

## 使用

- 在任何应用中选中文字 → **Ctrl+C**（复制）→ 鼠标旁弹出翻译
- 右键**托盘图标**（miaomiao翻译助手）→ 设置（弹窗宽度/划词字号/翻译字号/背景色/透明度/复制键色/关闭键色/圆角）/ 退出
- 浏览器打开 http://127.0.0.1:6688 可使用完整网页界面（词典查词、联想、纠错、神经翻译）

## 说明

- 划词助手为纯 PowerShell 脚本（`windows/xuanci_helper.ps1`），需 `powershell.exe`（Windows 10/11 自带，脚本已用 `-STA` 启动）
- 首次运行若被 SmartScreen/杀软提示，属正常（未签名脚本），选"仍要运行"
- 全部功能离线可用，不联网、不上传任何内容
