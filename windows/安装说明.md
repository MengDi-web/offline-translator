# Windows 版安装说明

本翻译器为**完全离线**的本地网页翻译：服务启动后，在浏览器里输入网址即可使用，不需要安装任何软件。

## 安装步骤（只需两步）

1. **双击「一键部署.cmd」** → 自动下载安装 Node / Python / 翻译模型（首次约 5-15 分钟，需联网，全程不用操作）

2. **之后每次使用：双击「启动翻译器.bat」** → 保持窗口打开 → 打开浏览器，**地址栏输入**：
   ```
   http://127.0.0.1:6688
   ```
   回车即可翻译（中英互译，输入后自动翻译，可查词、纠错、整句神经翻译）。

> 说明：`启动翻译器.bat` 的黑色窗口就是服务本身，**不要关闭**，关掉它就停止翻译了。
> 划词助手会随启动翻译器.bat 自动运行（托盘图标，最小化窗口）。

## 划词翻译（可选）

1. 在网页上**点一次「开启一键划词」**按钮（只需一次）
2. 之后在**任何软件**里选中文字 → **Ctrl+C**（复制）→ 鼠标旁弹出翻译
3. 右键**托盘图标**可设置/退出（托盘 = 屏幕右下角时间旁的小箭头里）

> 划词不依赖网页开着：开启后关掉浏览器也能用（只要黑色窗口没关）。

## 常见问题

- **双击启动翻译器.bat 提示"未找到 Node.js"** → 说明还没运行过「一键部署.cmd」，先运行它
- **浏览器打不开页面** → 确认黑色窗口还开着；地址栏输入的是 `http://127.0.0.1:6688`（不是别的）
- **首次被 Windows 提示** → 选「仍要运行」即可

## 系统要求

- Windows 10 / 11（64 位）
- 首次部署需要联网（之后使用完全离线，不上传任何内容）
