# 高质量长难句翻译数据库（中英对照）

面向**离线翻译器训练**的自建平行语料库：**300条长难句**，覆盖 **10大领域**，每条均为英文原句 + 高质量中文译文。

## 文件说明

| 文件 | 格式 | 用途 |
| --- | --- | --- |
| `长难句翻译数据库.json` | JSON（含 meta 元数据 + data 数组） | 结构化存取、按领域/难度筛选 |
| `长难句翻译数据库.jsonl` | JSON Lines（每行一条记录） | **训练首选**：可直接流式读入模型微调流程 |
| `长难句翻译数据库.tsv` | TSV（`英文	中文` 每行一对） | 通用平行语料格式，适配各类预处理工具 |

## 数据样例

```json
{
  "id": 1,
  "domain": "科学技术",
  "domain_en": "Science & Technology",
  "difficulty": "高级",
  "source_type": "学术论文与科普文献",
  "en": "Although the discovery of the Higgs boson in 2012 confirmed the last missing piece of the Standard Model of particle physics, ...",
  "zh": "尽管2012年希格斯玻色子的发现证实了粒子物理标准模型中最后缺失的一块拼图，……"
}
```

## 质量特征

- **长难句**：英文平均 **63词/句**（最短40词、最长92词），普遍包含多重从句、分词/介词短语插入语、并列结构、倒装与破折号插入成分，覆盖定语从句、状语从句、名词性从句等全部复杂句型。
- **中文译文**：平均111字/句，遵循中文表达习惯进行语序重组（长定语拆分、从句前置/后置、范畴词增补），非逐字对译，可作为高质量参考译文用于评测。
- **无版权风险**：全部语料为原创撰写，不摘录任何受版权保护的出版物原文，可用于训练与再发布。
- **术语密度高**：每个领域包含该领域高频术语（如 CRISPR、量子纠缠、jus cogens、净现值、Pax Mongolica 等），便于检验翻译模型的术语处理能力。

## 使用建议

1. **模型微调**：直接读取 `长难句翻译数据库.jsonl`，按 `en → zh` 方向训练；如需反向翻译（zh → en）可互换两列。
2. **评测集划分**：可按 `domain` 字段按领域划分，考察模型各领域的专项表现；或按 id 随机抽 10%~20% 作为留出集。
3. **数据增强**：可与基础平行语料混用，将本库作为“长难句专项”补充数据，显著提升模型对复杂句式的处理能力。
