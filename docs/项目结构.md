# 项目结构说明

> 整理时间：2025-11-20 · 整理后体积 7.0G → 3.3G

## 一句话

**改代码 → 跑两个脚本 → 得到安装包。**

```bash
# 1) 改了代码 → 同步进 dist 里的 app 并重签名（见下方"三个坑"）
# 2) 出包（唯一需要跑的脚本）
bash tools/build-cloud-package.sh     # → dist/网盘分发/{macOS,Windows}/
```

> `tools/build-macos-app.sh`：只在需要重建 .app 骨架时跑（换 Node/模型/依赖）。
> `tools/legacy/build-dist-package.sh`：**已废弃**（生成的是不含模型的源码包），保留仅作参考。

## 三个容易踩的坑

1. **改完要同步两个 app**：`dist/miaomiao翻译器.app`（打包源）和 `/Applications/miaomiao翻译器.app`（本机在跑的那个），改完都要 `codesign --force --sign - --deep`。
2. **/Applications 写入需要提权**：普通命令会静默失败，必须用提权模式，改完用 `cmp`/`codesign -v` 验证。
3. **样式改动刷新页面即可**：页面是 `public/index.html`；服务端逻辑改动要重启 app（`pkill -f server.js` 后重新 `/Applications/miaomiao翻译器.app/Contents/MacOS/launcher`）。

## 训练相关

```bash
# 训练集: neural/data/tune-en2zh/train.{en,zh}（素材 160 对 + 回放 1200 对）
# 评测集: neural/data/tune-eval/dev.{en,zh}（28 条，不参与训练）
APP="dist/miaomiao翻译器.app/Contents/Resources"
PYTHONPATH="$APP/python-libs" "$APP/python/bin/python3.12" neural/fine_tune.py \
  --orientation en2zh --data tune-en2zh --dev_dir clean \
  --model neural/models/opus-mt-en-zh-ft \
  --epochs 2 --lr 3e-5 --batch 16 --max_len 128 --dev_limit 100 \
  --device mps --tag en2zh-v3
```

要点：
- **必须 `--device mps` 或 cpu，且模型会在训练前转 fp32**——发布模型是 fp16，直接在 fp16 上跑 AdamW 会 NaN
- MPS 上若仍出 NaN 用 `--device cpu`（约 100 秒/步，只适合小数据）
- 训练检查点存 `neural/checkpoints/`（已被 .gitignore 和打包脚本排除）
- 训练完用 `/tmp/install_ft.py` 转成 fp16 覆盖 `neural/models/opus-mt-en-zh-ft/pytorch_model.bin`
